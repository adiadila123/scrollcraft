<section className="sec">
  <Stick left="03 · One loop for the whole site" right="requestAnimationFrame" />
  <div className="rows">
    <Row cls="rv" num="a" title="Why one">
      <p>Ten effects with ten loops each read the scroll position and each write styles, in an order nobody controls. One loop reads once and updates everything in the same frame, and it can stop when the tab is hidden.</p>
      <CodeBlock lang="ticker.js" code={"// ticker.js: one requestAnimationFrame loop for the whole site\nconst jobs = new Set();\nlet raf = 0;\n\nfunction frame(time) {\n  for (const job of jobs) job(time);\n  raf = jobs.size ? requestAnimationFrame(frame) : 0;\n}\n\n/** Run fn every frame. Returns a function that stops it. */\nexport function onFrame(fn) {\n  jobs.add(fn);\n  if (!raf && !document.hidden) raf = requestAnimationFrame(frame);\n  return () => jobs.delete(fn);\n}\n\n// stop drawing while the tab is hidden, start again when it comes back\ndocument.addEventListener('visibilitychange', () => {\n  if (document.hidden) { cancelAnimationFrame(raf); raf = 0; }\n  else if (jobs.size && !raf) raf = requestAnimationFrame(frame);\n});"} />
    </Row>
    <Row cls="rv" num="b" title="Lenis and GSAP share it">
      <p>If the site uses GSAP, its ticker is the loop: drive Lenis from <code className="i">gsap.ticker</code> as shown in the GSAP chapter, and add your own effects to the same ticker.</p>

In the Next.js App Router the component needs <code className="i">‘use client’</code> because it touches the browser. This sketch was not run here; install{' '}<code className="i">lenis</code> and <code className="i">gsap</code> with npm and test it in your project.</p>
