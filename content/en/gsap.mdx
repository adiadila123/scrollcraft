    <Row cls="rv sticky-k" num="2" title="Scrub">
      <p>With <code className="i">scrub</code>, the scroll position becomes the playhead: scrolling down plays the timeline, scrolling up rewinds it.</p>
      <p className="tip">A number such as <code className="i">scrub: 0.6</code> lets the playhead catch up over 0.6 seconds, which smooths a jerky wheel.</p>
    </Row>

    <Row cls="rv sticky-k" num="3" title="Pin">
      <p>Pinning holds a section in place while the reader keeps scrolling, and gives the timeline that distance to play in.</p>
      <p className="tip">Set <code className="i">end: &apos;+=200%&apos;</code> to pin for twice the screen height. Pin one section at a time, and never inside a transformed parent.</p>

  <Stick left="03 · In React and Next.js" right="useGSAP" />
  <div className="rows">
    <Row cls="rv" num="a" title="Clean up on unmount">
      <p>The <code className="i">useGSAP</code> hook from <code className="i">@gsap/react</code> scopes every selector to one component and reverts every animation and trigger when it unmounts, so client-side navigation leaves nothing behind.</p>
      <CodeBlock lang="tsx" code={"// components/Reveal.tsx\n'use client';\nimport { useRef, type ReactNode } from 'react';\nimport gsap from 'gsap';\nimport { ScrollTrigger } from 'gsap/ScrollTrigger';\nimport { useGSAP } from '@gsap/react';\n\ngsap.registerPlugin(useGSAP, ScrollTrigger);\n\nexport default function Reveal({ children }: { children: ReactNode }) {\n  const root = useRef<HTMLDivElement>(null);\n\n  // Everything created inside is scoped to root and reverted on unmount.\n  useGSAP(() => {\n    const mm = gsap.matchMedia();\n    mm.add('(prefers-reduced-motion: no-preference)', () => {\n      gsap.from('.reveal', {\n        y: 28, opacity: 0, duration: 0.9, ease: 'power3.out', stagger: 0.08,\n        scrollTrigger: { trigger: root.current, start: 'top 80%', once: true },\n      });\n    });\n  }, { scope: root });\n\n  return <div ref={root}>{children}</div>;\n}"} />
    </Row>
    <Row cls="rv" num="b" title="Respect reduced motion with matchMedia">
      <p><code className="i">gsap.matchMedia()</code> builds animations only while a media query matches and undoes them when it stops matching. Every preview in this chapter wraps its scroll animations in <code className="i">(prefers-reduced-motion: no-preference)</code>.</p>
    </Row>
