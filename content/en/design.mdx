  <div className="rows">
    <Row cls="rv" num="a" title="Colour">
      <p>Name colours by their job, not their hue: <code className="i">--accent</code> and <code className="i">--muted</code>, not <code className="i">--blue</code>. A minimalist page needs five or six, with one accent.</p>
    </Row>
    <Row cls="rv" num="b" title="Type">
      <p>A scale of four or five steps. Each step is a <code className="i">clamp()</code>, so headings grow with the screen without a breakpoint for every size.</p>
    </Row>
    <Row cls="rv" num="c" title="Space">
      <p>One unit and its multiples. When every gap is 8, 16, 24, 48 or 96, sections line up without anyone measuring.</p>
    </Row>
    <Row cls="rv" num="d" title="Motion">
      <p>Durations, easing curves and distances are design decisions too. Three durations and two curves cover almost every movement on a scroll site.</p>
      <CodeBlock lang="style.css" code={":root {\n  /* colour: named by role, not by hue */\n  --bg: #000;  --surface: #070a0d;  --line: #20262b;\n  --fg: #eaf0f4;  --muted: #8d989f;  --accent: #5cc8ff;\n\n  /* type: a short scale that grows with the screen */\n  --t-sm: 13px;\n  --t-md: clamp(15px, 1.2vw + 12px, 18px);\n  --t-lg: clamp(22px, 2.4vw + 14px, 32px);\n  --t-xl: clamp(40px, 8vw, 112px);\n\n  /* space: one unit and its multiples */\n  --s1: 8px;  --s2: 16px;  --s3: 24px;  --s4: 48px;  --s5: 96px;\n\n  /* motion: three durations, two curves, one distance */\n  --dur-fast: .2s;  --dur-base: .6s;  --dur-slow: 1.2s;\n  --ease-out: cubic-bezier(.2, .7, .2, 1);\n  --ease-in-out: cubic-bezier(.65, 0, .35, 1);\n  --rise: 24px;\n}"} />

  <Stick left="03 · Components read tokens" right="Never raw values" />
  <div className="rows">
    <Row cls="rv" num="a" title="One rule">
      <p>A component never writes a raw colour, size, gap or duration. If it needs a value that is not there, add a token first, then use it.</p>
      <CodeBlock lang="style.css" code={".btn {\n  padding: var(--s1) var(--s3);\n  font-size: var(--t-sm);\n  color: var(--fg);\n  border: 1px solid var(--line);\n  border-radius: 99px;\n  transition: border-color var(--dur-fast) var(--ease-out);\n}\n.btn:hover, .btn:focus-visible { border-color: var(--accent); }\n\n/* a variant changes tokens, not rules */\n.btn[data-tone=\"solid\"] { background: var(--accent); color: var(--bg); border-color: var(--accent); }"} />
    </Row>
    <Row cls="rv" num="b" title="Variants through attributes">
      <p>A variant such as <code className="i">data-tone="solid"</code> swaps a few tokens. The markup stays readable, and the AI cannot invent a seventh shade of grey.</p>
    </Row>
    <Row cls="rv" num="c" title="With Tailwind">
      <p>In Tailwind 4 the same tokens go in an <code className="i">@theme</code> block, and become classes like <code className="i">bg-accent</code>. The rule does not change: utilities only, no arbitrary values.</p>
    </Row>
